--------------==[Горячие клавиши эмулятора]==--------------
[F1]            - Помощь                                   
[F2]            - Меню сохранения                          
[F3]            - Меню загрузки                            
[Win]/[Home]    - Файловый менеджер                        
                                                           
[Ctrl+F1-F10]   - Сохр. образа .z80 в папку "SAVE" SD карты
[Shift+F1-F10]  - Загр.образа .z80 из папки "SAVE" SD карты
[Menu]/[Alt+F12]- Отобр. свободные слоты сохранения "SAVE" 
[F11]           - Включение выключение HUD                 
[F12]/[PrnScreen] - Вызов быстрого меню                    
[Pause]         - Остановка эмуляции                       
                                                           
[Ctrl+Alt+Del]  - Сброс эмулятора                          
[Ctrl+Alt+Ins]  - NMI эмулятора                            
[Shift+Alt+Del] - Сброс контроллера                        
[Ctrl+Alt+BSpace]- Сброс до настроек по умолчанию и        
                                     перезапуск контроллера
[NumPad +]/[Alt+PgUp] - Прибавить громкость эмуляции       
[NumPad -]/[Alt+PgDn] - Убавить громкость эмуляции         
[NumPad *]/[Alt+End]  - Включить/выключить режим Mute      
[NumPad /]/[Alt+Del]  - Переключение набора огибающих в STS
                                                           
-----------------=[Работа с "лентой" .tap]=----------------
[F5]            - Cтарт ленты                              
[F6]            - Остановка ленты, повторно в режиме       
                            остановки: перемотка на начало 
[F7]            - Cледующий блок                           
[F8]            - Предыдущий блок                          
[F9]            - Выброс "кассеты"                       
                                                           
*************************[Джойстик]************************
[START]         - Вызов быстрого меню                      
                  / Выход из файлового менеджера           
[A]             - Выбор файла                              
[C]             - Выход на уровень вверх                   
                                                           
---------------------=[Меню джойстика]=--------------------
[FILE BROWSER]  - Вызов менеджера файлов                   
  [KEYBOARD]    - Вызов экранной клавиатуры                
    [SAVE]      - Вызов списка слотов для сохранения игр   
    [LOAD]      - Вызов списка слотов для загрузки игр     
    [TAPE]      - Вызов меню управления виртуальной лентой 
    [POKE]      - Вызов меню ввода чит кодов               
    [HELP]      - Вызов текста помощи                      
8bit Kempston[ ]- Включает режим передачи всех кнопок 
				  джойстика в эмуляцию. Выход из режима 
				  START+SELECT
  [SETTINGS]    - Вызов меню настроек эмуляции             
  Soft reset    - Перезапуск эмуляции                      
  Hard reset    - Перезагрузка системы                     
                                                           
----------------=[Быстрые команды джойстика]=--------------
[START]+[UP]    - Следующий маппинг джойстика              
[START]+[DOWN]  - Предыдущий маппинг джойстика             
[START]+[LEFT]  - Быстрое сохранение                       
[START]+[RIGHT] - Быстрая загрузка                         
[START]+[A]     - Экранная клавиатура                      
[START]+[B]     - Файловый менеджер                        
                                                           
[SELECT]+[UP]   - Увеличение громкости                     
[SELECT]+[DOWN] - Уменьшение громкости                     
[SELECT]+[LEFT] - [TFT режим] Уменьшение яркости           
[SELECT]+[RIGHT]- [TFT режим] Увеличение яркости           
[SELECT]+[A]    - [TFT режим] Блокировка клавиатуры        
[SELECT]+[B]    - [TFT режим] Разблокировка клавиатуры     
                                                           
---------------------=[Джойстик в игре]=-------------------
[START]         - Вызов быстрого меню                      
                 / Выход из файлового менеджера            
[A]             - Действие назначенное в игре              
[B]             - Действие назначенное в игре              
[С]             - Действие назначенное в игре              
                                                           
------------=[Навигация в файловом менеджере]=-------------
[Курсорные клавиши:]                                       
[Стрелка влево]  - Начало списка                           
[Стрелка вправо] - Конец списка                            
[Стрелка вверх]  - Предыдущий файл                         
[Стрелка вниз]   - Следующий файл                          
[PageUp]         - Страница вверх                          
[PageDn]         - Страница вниз                           
[Enter]          - Запуск образа                           
[BackSpace]    - Выход на один каталог выше текущего уровня
[PrnScreen]   - Переключение просмотра заставки/содержимого
                                                           
[Ins]/[Space]  - Пометка файлов для удаления               
[Shift+Delete] - Вызов диалога удаления файлов             
                                                           
------------------=[Наcтройки эмулятора]=------------------
[F12]  - Настройки эмулятора (Доступны из файл менеджера)  
                                                           
 [Boot go to]    - Выбор типа стартового экрана            
  [LOGO]         - Показать заставку после старта          
  [FILE MANAGER] - Показать Файловый менеджер после старта 
  [EMULATION]    - Запустить эмуляцию после старта         
                                                           
 [Head Up Display]- Включение иконок поверх экрана         
  [On]           - Включить отображение занятых дисководов,
                   процесса загрузки и слотов сохранения   
  [Off]          - Чистый экран эмуляции                   
                                                           
 [Tap load]      - Настройки загрузки .tap файлов          
  [NORMAL LOADING] - Ручная загрузка образов .tap          
                     (смотри раздел "Работа с "лентой")    
  [AUTOSTOP LOADING] - Автоматическая загрузка через ROM   
  [FAST LOADING] - Быстрая загрузка через ROM              
                                                           
 [Ext tape load pin] - Настройка номера пина               
                       для внешней загрузки с магнитофона  
  [GPIO22]           - Загрузка программ через GPIO22      
  [GPIO29]           - Загрузка программ через GPIO29      
                                                           
 [Def joy mode]  - Режим джойстика                         
  [Ext>Kempston] - К [Kempston] подключен внешний джойстик 
  [Kbd>Kempston] - Эмуляция [Kempston] с клавиатуры        
                   (Курсорные + RAlt)                      
  [Kbd>Intface2] - Курсорные клавиши как Interface2        
  [ Kbd>Cursor ] - Курсорные клавиши как CursorJoystick    
  [-=+[NONE]+=-] - Все выключено                           
                                                           
 [Reboot ZX before load] - Сброс эмуляции перед загрузкой  
  [Yes] - Перезапускать эмуляцию при загрузке образов      
  [No]  - Не перезапускать эмуляцию  при загрузке образов  
                                                           
 [Snd mode] - Переключение вывода звука                    
  [-=[Sound OFF]=-] - Выключить весь звук                  
  [  Only Beeper  ] - Вывод звука только с бипера			
  [ Beeper+SoftAY ] - Звук с бипера и эмуляции AY-3-8910   
  [ Beeper+SoftTS ] - Звук с бипера и эмуляции TurboSound  
  [ HW TurboSound ] - Звук с аппаратного TurboSound        
                                                           
 [Soft Sound Vol] - Громкость звука эмуляции               
                   (работает только в Soft режиме)         
                                                           
 [Video output] -Выбор типа подключения для вывода изображ.
  [   AUTO   ] - Автоопределение (VGA/HDMI)                
  [   VGA    ] - Вывод на VGA разъем                       
  [   HDMI   ] - Вывод на HDMI разъем                      
  [  ST7789  ] - Вывод на ЖК экран с чипом ST7789          
  [  ST7789V ] - Вывод на ЖК экран с чипом ST7789V         
  [  ILI9341 ] - Вывод на ЖК экран с чипом ILI9341         
  [ ILI9341V ] - Вывод на ЖК экран с чипом ILI9341V        
  [  GC9A01  ] - Вывод на ЖК экран с чипом GC9A01          
                   Для применения нужна перезагрузка.      
                                                           
 [Video framerate] - Переключение частоты обновления       
  [60Hz] - подходит для большинства LCD мониторов          
  [72Hz] - подходит для большинства LCD/HDMI мониторов     
  [75Hz] - подходит для LCD/HDMI/CRT мониторов             
  [85Hz] - подходит для CRT мониторов                      
                   Для применения нужна перезагрузка.      
                                                           
 [LCD BrightLev] - Уровнь яркости подсветки ЖК экрана      
               (работает только с режимами: ST7789,ST7789V,
                                   ILI9341,ILI9341V,GC9A01)
                                                           
 [LCD Rotate] - Поворот изображения ЖК экрана              
  [Horizont R] - Горизонтальное, разъем дисплея справа     
  [Vertical R] - Вертикальное, разъем дисплея снизу        
  [Horizont L] - Горизонтальное, разъем дисплея слева      
  [Vertical L] - Вертикальное, разъем дисплея сверху       
               (работает только с режимами: ST7789,ST7789V,
                                   ILI9341,ILI9341V,GC9A01)
                   Для применения нужна перезагрузка.      
                                                           
 [LCD inversion] - Инверсия изображения ЖК экрана          
  [ NORMAL ] - Нормальное изображение                      
  [INVERTED] - Инверсия цветов изображения                 
               (работает только с режимами: ST7789,ST7789V,
                                   ILI9341,ILI9341V,GC9A01)
                   Для применения нужна перезагрузка.      
                                                           
 [LCD Pixel format] - Формат пикселей ЖК экрана            
  [ BGR ] - Blue Green Red, обратный порядок               
  [ RGB ] - Red Green Blue, прямой порядок                 
               (работает только с режимами: ST7789,ST7789V,
                                   ILI9341,ILI9341V,GC9A01)
                   Для применения нужна перезагрузка.      
                                                           
 [HW TS Main Chip] - Выбор главного чипа TurboSound        
  [Chip 1] - первый чип TurboSound адресует порт 0xFF      
  [Chip 2] - первый чип TurboSound адресует порт 0xFE      
                                                           
 [LOAD]     - Загрузить настройки c SD                     
 [DEFAULT]  - Загрузить настройки по умолчанию             
              и перезаписать файл настроек                 
 [SAVE]     - Сохранить настройки на SD                    
 [UPDATE FIRMWARE]-Перезагрузка в режим обновления прошивки
 [!!!REBOOT!!!]   - Перезагрузка контроллера
