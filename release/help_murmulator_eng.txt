-------------==[Emulator Keyboard Shortcuts]==-------------
[F1] - Help                                                
[F2] - Quick Save Menu                                     
[F3] - Quick Load Menu                                     
[Win]/[Home] - File Manager                                
                                                           
[Ctrl+F1-F10] - Save the .z80 image to "SAVE" folder     
[Shift+F1-F10] - .z80 Image load from "SAVE" folder      
[Menu]/[Alt+F12]- Show free save slots at "SAVE" folder  
[F11] - Enable disable HUD                                 
[F12]/[PrnScreen] - Quick menu call                        
[Pause] - Pauses emulation                                 
                                                           
[Ctrl+Alt+Del] - Reset the emulator                        
[Ctrl+Alt+Ins] - NMI emulator                              
[Shift+Alt+Del] - Reset the controller                     
[Ctrl+Alt+BSpace]- Set default settings and                
                                          reboot controller
[NumPad +]/[Alt+PgUp] - Volume Up of the emulation         
[NumPad -]/[Alt+PgDn] - Volume Down of the emulation       
[NumPad *]/[Alt+End] - Enable/disable Mute mode            
[NumPad /]/[Alt+Del] -Switch the envelope in SoftTurboSound
                                                           
---------------=[Working with "Tape" .tap]=--------------
[F5] - Start playing tape                                  
[F6] - Stop the tape, repeat: rewind to the beginning      
                                                           
[F7] - Next block                                          
[F8] - Previous block                                      
[F9] - Eject current tape                                  
                                                           
*************************[Joystick]************************
[START]     - Quick menu call                              
        / Exiting the file manager                         
[A] - File Selection                                       
[C] - Exit to top folder                                   
                                                           
---------------------=[Joystick Menu]=---------------------
[FILE BROWSER] - Calling the file manager                  
  [KEYBOARD] - Calling the on-screen keyboard              
  [SAVE] - List of slots to save games                     
  [LOAD] - List of slots for load games                    
  [TAPE] - Open the virtual tape management menu           
  [POKE] - Cheat code entry menu                           
  [HELP] - Help                                            
8bit Kempston[ ]- Enables translation of all joystick button 
				  to the emulation. Exit the mode by START+SELECT
  [SETTINGS] - Emulation settings menu                     
  Soft reset - Restarting the emulation                    
  Hard reset - Restarting the system                       
                                                           
-------------------=[Joystick hat switch]=-----------------
[START]+[UP]    - Next joystick mapping                    
[START]+[DOWN]  - Prev joystick mapping                    
[START]+[LEFT]  - Quick save                               
[START]+[RIGHT] - Quick load                               
[START]+[A]     - On screen keyboard                       
[START]+[B]     - File manager                             
                                                           
[SELECT]+[UP]   - Volume Up                                
[SELECT]+[DOWN] - Volume Down                              
[SELECT]+[LEFT] - [TFT mode] Brightness Level Down         
[SELECT]+[RIGHT]- [TFT mode] Brightness Level Up           
[SELECT]+[A]    - [TFT mode] Keyboard Lock                 
[SELECT]+[B]    - [TFT mode] Keyboard Unlock               
                                                           
---------------------=[In-game joystick]=------------------
[START]       - Quick menu call                            
         / Exiting the file manager                        
[A] - The action assigned in the game                      
[B] - The action assigned in the game                      
[C] - The action assigned in the game                      
                                                           
----------------=[File Manager Navigation]=----------------
[Cursor keys:]                                             
[Left arrow]  - Start of the list                          
[Right arrow] - End of the list                            
[Up Arrow]    - Previous file                              
[Down arrow]  - Next file                                  
[PageUp]      - Page up                                    
[PageDn]      - Page down

-------------------=[Emulator Settings]=-------------------
[F12] - Emulator settings (Available from the file manager)
                                                           
 [Boot go to] - Select the type of start splash screen     
  [LOGO]     - Show splash screen after the start          
  [FILE MANAGER] - Show the File Manager after startup     
  [EMULATION] - Start emulation after startup              
                                                           
 [Head Up Display]- Enabling icons on top of the screen    
  [On]            - Enable the display of occupied drives, 
                    loading process and save slots         
  [Off]           - Clean emulation screen                 
  [Time]          - HUD disappear by time                  
                                                           
 [Tap load]  - .tap files loading settings                 
  [NORMAL LOADING] - Manual loading of images .tap         
                     (see "Working with "tape" section)
  [AUTOSTOP LOADING] - Automatic loading via ROM           
  [FAST LOADING] - Fast loading via ROM                    
                                                           
 [Ext tape load pin] - Setting the pin number              
                 for external loading from a tape recorder 
  [GPIO22] - Loading programs via GPIO22                   
  [GPIO29] - Loading programs via GPIO29                   
                                                           
 [Def joy mode] - Default joystick mode                    
  [Ext>Kempston] - External joystick mapped to [Kempston]  
  [Kbd>Kempston] - Emulation of [Kempston] from keyboard   
                   (Cursors + RAlt)                        
  [Kbd>Intface2] - Cursor keys as Interface2               
  [ Kbd>Cursor ] - Cursor keys as CursorJoystick           
  [-=+[NONE]+=-] - Everything is off                       
                                                           
 [Reboot ZX before load] - Reset emulation before loading  
  [Yes] - Restart emulation when loading images            
  [No] - Do not restart emulation when loading images      
                                                           
 [Snd mode] - Switching the audio output                   
  [-=[Sound OFF]=-] - Turn off all sound                   
  [ Only Beeper ] - Audio only from the beeper             
  [ Beeper+SoftAY ] - Beeper and emulation AY-3-8910       
  [ Beeper+SoftTS ] - Beeper and TurboSound emulation      
  [ HW TurboSound ] - External hardware TurboSound         
                                                           
 [Soft Sound Vol] - Sound Volume of the emulation          
                    (works only in Software emulation mode)
                                                           
 [Video output] - Video output type                        
  [ AUTO ] - Auto Detection (VGA/HDMI)                     
  [ VGA ] - Output to the VGA connector                    
  [ HDMI ] - Output to the HDMI connector                  
  [ ST7789 ]  - Output to LCD screen with the ST7789 chip  
  [ ST7789V ] - Output to LCD screen with the ST7789V chip 
  [ ILI9341 ] - Output to LCD screen with the ILI9341 chip 
  [ ILI9341V ]- Output to LCD screen with the ILI9341V chip
  [ GC9A01 ]  - Output to LCD screen with GC9A01 chip      
           A reboot is required to apply mode.             
                                                           
 [Video framerate] - Switching the vertical refresh rate   
  [60Hz] - Suitable for most LCD monitors                  
  [72Hz] - Suitable for most LCD/HDMI monitors             
  [75Hz] - Suitable for LCD/HDMI/CRT monitors              
  [85Hz] - Suitable for CRT monitors                       
           A reboot is required to apply mode.             
                                                           
 [LCD BrightLev] - The brightness level for LCD backlight  
                   (works only with modes: ST7789,ST7789V, 
                                   ILI9341,ILI9341V,GC9A01)
                                                           
 [LCD Rotate] - Rotate the image of the LCD screen         
  [Horizont R] - Horizontal, display connector on the right
  [Vertical R] - Vertical, display connector from below    
  [Horizont L] - Horizontal, display connector on the left 
  [Vertical L] - Vertical, display connector from above    
                    (works only with modes: ST7789,ST7789V,
                                   ILI9341,ILI9341V,GC9A01)
           A reboot is required to apply mode.             
                                                           
 [LCD inversion] - Inversion of the LCD screen image       
 [ NORMAL ] - Normal image                                 
 [INVERTED] - Inversion of image colors                    
                    (works only with modes: ST7789,ST7789V,
                                   ILI9341,ILI9341V,GC9A01)
           A reboot is required to apply mode.             
                                                           
 [LCD Pixel format] - LCD screen pixel format              
 [ BGR ] - Blue Green Red, reverse order                   
 [ RGB ] - Red Green Blue, forward order                   
                    (works only with modes: ST7789,ST7789V,
                                   ILI9341,ILI9341V,GC9A01)
           A reboot is required to apply mode.             
                                                           
 [HW TS Main Chip] - TurboSound main chip selection        
 [Chip 1] - the first TurboSound chip addresses port 0xFF  
 [Chip 2] - the first TurboSound chip addresses port 0xFE  
                                                           
 [LOAD]     - Reload settings from SD                      
 [DEFAULT]  - Load default settings                        
                           and overwrite the settings file 
 [SAVE]     - Save settings to SD card                     
 [UPDATE FIRMWARE] - Reboot to firmware update mode        
 [!!!REBOOT!!!] - Restart the controller
